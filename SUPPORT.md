# Support

## Before reporting an issue

1. Confirm that VS Code, Node.js, the Codex CLI, and `arecord` meet the requirements in the README.
2. Run `npm run compile`, `npm run lint`, and `npm test` if you are developing from source.
3. Check the VS Code Output panel for Sarvam Codewalk messages.
4. Do not include API keys, recordings, private source code, or `.env` contents in an issue.

## Report a bug

Open an issue at [GitHub Issues](https://github.com/Harizz076/sarvam-codewalk-extension/issues) with:

- VS Code version and Linux distribution
- Node.js version
- Extension version
- Steps to reproduce
- Expected and actual behavior
- A redacted error message, if available

## Security and privacy

Do not report security-sensitive issues in a public issue. Contact the repository owner privately through GitHub instead.
